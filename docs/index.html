Built to be trusted with your keys

A tool that reads your most sensitive files has to be boring and auditable. These rules are enforced in code and checked in CI.

  • No networkscan, fix, undo and doctor never open a connection. CI fails if net/http is imported anywhere but the update module.
  • Secrets stay maskedMatches become a SHA-256 fingerprint and a preview like ghp_••••7c3b. A test fails if any raw key reaches any output.
  • Scan only readsNothing is written until you run lootmap fix --yes, after it prints the full plan.
  • Every change can be undoneOriginals are backed up owner-only for 7 days. lootmap undo restores them byte for byte.
  • Live sessions are left aloneAI transcripts written in the last 60 seconds are skipped, so an agent mid-task is never disturbed.
  • Some things are off limitsBrowser password stores, OS keychains and crypto wallets are never read. No sudo, no telemetry, no account.

Run it in under a minute

lootmap is a single static binary for macOS, Linux and Windows. It is in preview; build it from source until the first signed release.

  1. Install with Go 1.23 or newer.

    go install github.com/lootmap-dev/lootmap/cmd/lootmap@latest

  2. See what is exposed. This only reads files.

    lootmap scan

  3. Preview the fixes, then apply them. Revoke anything still listed in your provider's console.

    lootmap fix --dry-run
lootmap fix --yes
lootmap explain --rotate   # links to each key's revoke page
